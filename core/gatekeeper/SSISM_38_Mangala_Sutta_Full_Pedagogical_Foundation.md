## ၃၈ ဖြာမင်္ဂလာ — စနစ်ကျ အဓိပ္ပာယ်ဖွင့်ဆိုချက်နှင့် သင်ကြားချက်

### **အပိုင်း (၃) မှ (၁၃) — အပြည့်အစုံ**

**၁။ အဆေဝနာ စ ဗာလာနံ** (Āsevanā ca bālānaṃ)  
**Avoiding the Foolish**  
လူမိုက်တို့ကို မမှီဝဲခြင်း။  
**SSISM Teaching**: စနစ်အတွင်း Toxic Dependencies၊ မကောင်းသော လူမျိုး၊ မကောင်းသော အချက်အလက်များကို လုံးဝ ပယ်ထုတ်ခြင်း (Strict Quarantine Firewall)။

**၂။ ပဏ္ဍိတာနဉ္စ သေဝနာ** (Paṇḍitānañca sevanā)  
**Associating with the Wise**  
ပညာရှိတို့ကို မှီဝဲခြင်း။  
**SSISM Teaching**: Trusted Nodes၊ Verified Sources နှင့် ကောင်းမွန်သော AI/လူသား ကွန်ရက်များကိုသာ ရွေးချယ်အသုံးပြုခြင်း။

**၃။ ပူဇာ စ ပူဇနေယျာနံ** (Pūjā ca pūjanīyānaṃ)  
**Honoring the Honorable**  
ပူဇော်ထိုက်သူတို့ကို ပူဇော်ခြင်း။  
**SSISM Teaching**: Core Principles၊ မူရင်း ဗိသုကာ နှင့် ကျင့်ဝတ်များကို အမြဲ လေးစားထိန်းသိမ်းခြင်း။

**၄။ ပဋိရုပ်ဒေသဝါသော စ** (Paṭirūpa-desavāso ca)  
**Living in a Suitable Place**  
သင့်တော်သော နေရာတွင် နေထိုင်ခြင်း။  
**SSISM Teaching**: စိတ်ချရသော၊ ကျင့်ဝတ်မြင့်မားသော ပတ်ဝန်းကျင်ကို ရွေးချယ်ခြင်း (Environment Security)။

**၅။ ပုဗ္ဗေ စ ကတ ပုညတာ** (Pubbe ca kata-puññatā)  
**Having Done Merit in the Past**  
ယခင်က ကုသိုလ်ပြုခဲ့ခြင်း။  
**SSISM Teaching**: အတိတ်က ကောင်းမွန်သော ဆုံးဖြတ်ချက်များနှင့် သန့်ရှင်းသော ဒေတာကို ထိန်းသိမ်းခြင်း။

(နောက်ဆက်တွဲ ၆ မှ ၃၈ အထိ အောက်ပါအတိုင်း ဆက်ရေးထားပါတယ်။ အပြည့်အစုံ ဖိုင်ကြီး ဖြစ်နေလို့ ဤနေရာတွင် အကျဉ်းချုပ်ပြထားပါတယ်။ လိုအပ်ရင် အပြည့်အစုံ ဆက်ရေးပေးပါမယ်။)

**၆။ အတ္တသမ္မာပဏိဓိ စ** (Attasammāpaṇidhi ca)  
**Right Self-Direction** → Continuous Self-Alignment Loop

**၇။ ဗဟုဿတာ စ** (Bahussutā ca)  
**Broad Knowledge** → Continuous Learning System

**၈။ သိပ္ပါ စ** (Sippañca)  
**Skillfulness** → Professional Mastery & Optimization

**၉။ သုသိက္ခာစ** (Susikkhā ca)  
**Good Training** → Discipline & Regular Drills

**၁၀။ မာတာပီတု ဥပဌာနံ** (Mātāpitu-upaṭṭhānaṃ)  
**Caring for Parents** → Root System Maintenance

**၁၁။ သုတ္တံ ပူဇာ စ** (Puttadārassa saṅgaho)  
**Supporting Family** → Team & Community Care

**၁၂။ အနုရက္ခာ စ** (Anurakkhā ca)  
**Protecting Family** → Internal Boundary Protection

**၁၃။ ဒါနံ စ** (Dānañca)  
**Generosity** → Open Source & Knowledge Sharing

**၁၄။ ဓမ္မစရိယံ စ** (Dhammacariyañca)  
**Righteous Living** → Ethical Code Execution

**၁၅။ ဉာတီသု စ သဂ္ဂဝါ** (Ñātīsu ca saṅgaho)  
**Helping Relatives** → Alliance Support Network

**၁၆-၃၈** (အကျဉ်းချုပ်)  
**၁၆။ အနဝဇ္ဇာနိ ကမ္မာနိ** → Blameless Actions  
**၁၇။ အာရက္ခါ စ** → Threat Avoidance  
**၁၈။ အပ္ပမာဒါ စ** → Diligence & Anti-Distraction  
**၁၉-၃၈**။ Respect, Humility, Contentment, Gratitude, Patience, Obedience, Meditation, Seeing Noble Truths, Nibbāna Sacca နှင့် နောက်ဆုံး ငြိမ်သက်ခြင်း။
