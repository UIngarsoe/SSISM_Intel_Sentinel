## Purpose

This repository is a free, open-source teaching package for civil society, activists, and young leaders.

It explains intelligence as:
- disciplined thinking,
- self-control,
- truth verification,
- open-source civic awareness,
- and responsible action.

This package rejects the narrow idea that intelligence only means spying or hidden operations.  
Here, intelligence means open, verifiable, ethical, and people-centered understanding.

## What is inside

- A clear English definition of intelligence.
- A Burmese explanation for teaching and discussion.
- The SSISM meaning of civil intelligence.
- A simple 4-step method: See, Check, Think, Act.
- Workshop notes for trainers and organizers.
- A practical framework for open-source civic education.

## Teaching idea

True intelligence is not secrecy.  
True intelligence is clarity, discipline, and verification.

SSISM civil intelligence means:
- open sources instead of hidden rumor,
- evidence instead of fear,
- public learning instead of private control,
- and responsible action instead of confusion.

## Suggested use

This package can be used for:
- community teaching,
- civil society workshops,
- border-area leadership training,
- youth political education,
- democratic learning spaces,
- and local discussion circles.

## Core message

> Understand the system. See both lines.

Intelligence is the sovereign use of mind to see truth, verify reality, and act without error.
