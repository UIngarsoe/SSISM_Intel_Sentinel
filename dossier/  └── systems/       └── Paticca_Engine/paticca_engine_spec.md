# Formal Specification — Paṭiccasamuppāda Engine

## 1. Cyclic Dependency Graph Model

The Paṭiccasamuppāda doctrine is modeled as a Directed Cyclic Graph (DCG).

Nodes represent states (nidānas).  
Edges represent causal transitions.

A → B → C → ... → L → A

This structure mirrors feedback systems used in systems engineering, AI reasoning loops, and cybersecurity propagation models.

## 2. Nodes (States)

A = Avijjā (Ignorance)  
B = Saṅkhāra (Formations)  
C = Viññāṇa (Consciousness)  
D = Nāmarūpa (Name & Form)  
E = Saḷāyatana (Six Bases)  
F = Phassa (Contact)  
G = Vedanā (Feeling)  
H = Taṇhā (Craving)  
I = Upādāna (Clinging)  
J = Bhava (Becoming)  
K = Jāti (Birth)  
L = Jarāmaraṇa (Aging & Death)

## 3. Firewall Rule (Kill-Switch Condition)

If Avijjā = False → Entire graph execution stops.

This is a global gate condition, equivalent to a firewall rule preventing cascade propagation.

## 4. ISM Deterministic Core Principle

Deterministic definition:

Same input → Same output → Always.

This aligns with verifiable systems, formal verification, and cryptographic integrity practices (e.g., SHA-256).
