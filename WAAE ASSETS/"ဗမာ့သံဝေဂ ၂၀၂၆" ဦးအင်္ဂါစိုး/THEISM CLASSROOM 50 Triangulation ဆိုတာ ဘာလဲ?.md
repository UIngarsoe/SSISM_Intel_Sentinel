၄။ Triangulation မှာ “Source Independence” က အရေးကြီးဆုံး

၁၅။ Sentinel Evidence Weight

Classroom 50 အတွက် ဒီ formula ကို သင်ပါ—

> Evidence Value = Reliability × Independence × Relevance × Diagnostic Value



ဒါဟာ mathematical law မဟုတ်ဘဲ teaching heuristic ဖြစ်ပါတယ်။

ဥပမာ—

Source တစ်ခုက reliable ဖြစ်ပေမယ့် claim နဲ့ မသက်ဆိုင်ရင်—

Relevance နည်း → Overall value နည်း

Source တစ်ခုက claim နဲ့ အလွန်သက်ဆိုင်ပေမယ့် အခြား source တစ်ခုကိုပဲ ပြန်ကူးထားရင်—

Independence နည်း → corroboration value နည်း
