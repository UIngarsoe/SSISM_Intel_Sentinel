# SSISM–Steinberg Legacy Package

This folder preserves and operationalizes the analytical methodology of
Professor David I. Steinberg into the SSISM Analytical Engine.

Contents:

- article.md — Academic article explaining the methodological translation
- ssism_steinberg_engine.py — Executable implementation of the method

Purpose:

To transform Steinberg’s methodological teaching on Burma/Myanmar into a
reproducible analytical discipline usable by both human researchers and AI systems.

SSISM Principle:
Method must be reproducible. Analysis must be verifiable. Knowledge must be tamper-evident.
